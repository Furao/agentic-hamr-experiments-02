# Open issues

This directory holds the canonical records for unresolved project findings.
Each record tracks its stable ID, criticality, status, owner, evidence, attempted
mitigations and closure criteria. Acceptance of a wave or test campaign does not
close an issue unless its resolution is explicitly recorded.

resolution evidence for traceability.
